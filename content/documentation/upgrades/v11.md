This document is intended to guide you when upgrading from GenHTTP 10.x to GenHTTP 11.

### API Rework

The dominant change of GenHTTP 11 is a reworked API layer that is better suited to represent
incoming HTTP requests and requires less work by the engine to process the data, resulting
in much higher performance (see the [HTTP Arena results](https://www.http-arena.com/)). For 
general information about how the new API works, see [Request API](../../content/concepts/request-api/).
